OneClickCopy for Windows
========================

Install
  1. Extract this zip anywhere (for example, your Downloads folder).
  2. Double-click Install.cmd.

  OneClickCopy installs for your user account only; no administrator rights
  are needed. It goes to %LOCALAPPDATA%\Programs\OneClickCopy, with Start menu
  and desktop shortcuts. You can delete the extracted folder afterwards.

  The app is not code-signed, so Windows SmartScreen may warn the first time
  you run Install.cmd or the app. Choose "More info", then "Run anyway".

Update
  Extract the newer zip and run its Install.cmd. Your documents are kept.

Uninstall
  Settings > Apps > Installed apps > OneClickCopy > Uninstall.
  Your documents stay in %APPDATA%\OneClickCopy until you delete that folder.

Your data
  Documents are saved in %APPDATA%\OneClickCopy\documents.json. Use
  "Export to file" in the account menu to move them to or from the Android
  app. GitHub backup (optional) works the same as on Android.

More: https://github.com/oilu23/OneClickCopy/blob/master/desktop/README.md
